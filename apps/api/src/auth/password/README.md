# Common-password blocklist

`common-passwords.txt` is the exact `Passwords/Common-Credentials/10k-most-common.txt`
snapshot from SecLists commit `0b41dd3c3204e120e1c9c46d8916e2faf8a80c80`.
SecLists is MIT-licensed. Source:
`https://github.com/danielmiessler/SecLists/blob/0b41dd3c3204e120e1c9c46d8916e2faf8a80c80/Passwords/Common-Credentials/10k-most-common.txt`.

The runtime and tests require exactly 10,000 unique NFC/lowercase entries and SHA-256
`4adb3f0afb4a10cf19ebe48d8c69a46f934bbc8d77c694c210564f9583e7f4ba`.
